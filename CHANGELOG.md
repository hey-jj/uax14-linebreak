# Changelog

## 0.1.0 - 2026-08-22

- Added Unicode 17.0.0 default line breaking for strings.
- Added indexed character iteration with caller-defined index types.
- Added raw `Line_Break` property lookup for all Unicode code points.
- Added safe restart splits for chunked text processing.
- Added full Unicode 17.0.0 conformance coverage and allocation checks.
- Added a performance check asserting linear scaling and a fixed throughput floor.
- Marked the package license as MIT AND Unicode-3.0 with the Unicode notice in LICENSE-UNICODE.
